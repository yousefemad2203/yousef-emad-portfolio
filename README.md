# Youssef Emad Portfolio

A responsive, dark-themed bilingual (English/Arabic) video editing portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and project links
- `style.css` — responsive design
- `script.js` — language switcher and mobile navigation
- `profile.jpg` — profile image used in the hero section

## Update or add a video later
1. Open `index.html` on GitHub and click the pencil icon to edit.
2. Find the `project-grid` section.
3. For an existing video, replace the YouTube video ID in the iframe URL (`https://www.youtube.com/embed/VIDEO_ID`) and update its title/link.
4. To add another video, duplicate one `<article class="project-card">...</article>` inside `project-grid`, then change the video ID, title, label, and link.
5. Click **Commit changes**. GitHub Pages will publish the update automatically.

A YouTube Shorts URL such as `https://youtube.com/shorts/QsG1AFOPVhE` uses the video ID `QsG1AFOPVhE`; the embedded player URL is `https://www.youtube.com/embed/QsG1AFOPVhE`.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save. Ensure `index.html`, `style.css`, `script.js`, and `profile.jpg` are in the repository root.
